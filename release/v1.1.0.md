# Unit Converter UI v1.1.0

This release turns the converter into a more focused, responsive workspace and
adds browser-local favorites for frequently used conversion directions.

## Highlights

- Added Favorites for saving an exact Category, Measure, From, and To unit
  combination. Saved directions are grouped by Category and Measure and can be
  loaded or removed from the converter workspace.
- Split the converter taxonomy into separate Category and Measure selectors,
  with the amount field positioned below the From and To unit controls.
- Refined the responsive visual system across converter, Units, and About pages,
  including clearer hierarchy, spacing, focus states, and mobile layouts.
- Limited displayed conversion results to a maximum of 10 fractional digits,
  with correct rounding and trailing-zero trimming.

## Favorites

- Favorites are stored only in the current browser profile through
  `localStorage`; they are not sent to the backend or shared with another
  browser or device.
- The exact conversion direction is unique, so the reverse direction can be
  saved as a separate favorite.
- Loading a favorite preserves the current amount, updates the converter, and
  returns keyboard focus to the Amount field.
- Changes are synchronized across tabs in the same browser profile without
  rebuilding the converter or resetting its in-progress input and focus.
- Empty, unavailable-storage, damaged-data, write-error, and stale-catalog
  states are handled without blocking conversion. Up to 50 favorites can be
  stored.

## Interface and Accessibility

- Preserved the Convert, Units, and About navigation and converter deep links.
- Added a skip link, clearer semantic headings and lists, descriptive live
  regions, keyboard focus recovery after deletion, and mobile-friendly controls
  with a 44 px favorite removal target.
- Added explicit loading, result, conversion error, catalog empty, Favorites
  empty, hover, and focus states.
- Improved the Units page with a visible result count and a keyboard-friendly
  clear-filter action.
- Updated select arrows and spacing while retaining the existing teal and
  orange design tokens and system font stack.

## Reliability and Security

- Prevented stale conversion responses from replacing a newer result after a
  fast Category, Measure, unit, or favorite change.
- Validated and bounded all persisted favorite fields, safely escaped catalog
  and favorite content, and recovered from unavailable or malformed browser
  storage.
- Restricted the built-in HTTP server to public UI assets, capped conversion
  request bodies, rejected non-finite or unbounded Decimal input, and added
  browser security headers.
- Replaced internal package and conversion exception details with stable public
  API error messages.
- Added version consistency checks and focused tests for result formatting,
  converter selection, navigation, request ordering, Favorites persistence,
  grouping, storage failures, and cross-tab synchronization.
- Added no new runtime dependencies. The backend conversion behavior and
  successful conversion response remain unchanged; invalid and error responses
  now enforce stricter boundaries and expose fewer internal details.

## Upgrade and Rollback

- No backend, account, database, or dependency migration is required.
- Existing v1.0.0 users begin with an empty Favorites panel. Clearing this
  site's browser data removes saved favorites.
- To roll back the UI, redeploy the immutable `v1.0.0` tag. The v1.1.0
  Favorites storage entry is ignored by v1.0.0 and can remain in the browser.
