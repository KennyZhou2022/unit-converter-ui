# Unit Converter UI v1.0.0

Initial release of the Unit Converter web UI.

## Highlights

- Added a build-free browser UI for standards-backed unit conversions.
- Added grouped converter browsing, focused converter pages, and a searchable
  supported-unit catalog.
- Added a Python standard-library HTTP adapter that exposes catalog, unit, and
  conversion endpoints to the browser.
- Integrated `unit-converter` 1.3.0 as the backend package for local wheel-based
  testing and general cloud deployment from the GitHub release tag.
- Added About links for the NIST source PDF, backend package releases, GitHub
  issues, and this UI repository.
- Added the current backend wheel package version to the About page.
- Added a visible `v1.0.0` UI version badge in the top navigation.

## Backend Package

- Backend package: `unit-converter` 1.3.0.
- Source data: NIST Special Publication 811 (2008), Appendix B.9.
- Runtime conversion behavior is unchanged from `unit-converter` 1.2.0 according
  to the backend package release notes.

## Verification

- JavaScript syntax check passes for all files under `src/`.
- Python adapter compilation passes.
- `/api/health` reports `uiVersion: "1.0.0"` and `packageVersion: "1.3.0"` when
  run with the local virtual environment.
